# MIL-STD, DO-254, FIPS 140-3 and Common Criteria assurance matrix

QSAG is a research prototype with no external audit. This matrix records the engineering evidence available for an assurance review and the work that still requires deployment artifacts, manufactured devices or independent evaluation. “Closed” refers to the specific engineering obligation named in a row.

## Standards and evidence boundaries

| Review domain | Evidence available for review | Additional evidence for qualification |
| --- | --- | --- |
| DO-254 Level A and MIL-PRF-38535 hardware assurance | RTL, component equivalence checks, full-proof simulation, mapped logic area, routed FPGA bitstreams and an enclave floorplan for the 56-pad wafer.space shuttle. | Requirements traceability, independent verification and target-specific timing, layout and manufacturing qualification. |
| MIL-STD-883 microelectronics testing | Pre-silicon simulation and physical implementation data identify structures and operating assumptions to test. | Fabricated-device environmental, reliability and physical tests against the intended qualification profile. |
| FIPS 140-3 Level 4 and NIST SP 800-90B | RTL for lifecycle access control, zeroization, and repetition-count and adaptive-proportion health tests on entropy samples. | Entropy characterization on devices, module-boundary and physical-security testing, and accredited evaluation. |
| MIL-STD-498, IEEE 1012 and Common Criteria EAL7 | Constructive protocol specifications, extracted Rust MIR, independent kernel replay, compiled mutation tests and Lean–Rust–RTL cross-checks. | System requirements and implementation traceability, deployment assumptions and independent assessment of the evaluated configuration. |
