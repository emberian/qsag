# MIL-STD / DO-254 / FIPS 140-3 / Common Criteria EAL7 Assurance & Gap Matrix

This document benchmarks `qsag` against concrete defense, avionics, cryptographic-module, and formal-methods standards (**DO-254 Level A**, **MIL-PRF-38535**, **MIL-STD-883**, **FIPS 140-3 Level 4 / NIST SP 800-90B**, **MIL-STD-498 / IEEE 1012**, and **Common Criteria EAL7**) rather than ad-hoc project checklists.

**Non-Negotiable Physical Constraint:** For `GF180MCU-D` (`wafer.space`), **`SLOT_0P5X0P5` (`1,936 × 2,531 µm` die, `1.726 mm²` core, `56` pads) is the ONLY permitted tapeout slot.** Increasing die size to `SLOT_0P5X1` or silencing EDA signoff checks (`ERROR_ON_*: false`) does not satisfy physical signoff.
